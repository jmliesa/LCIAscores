# LCIA Scores
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.14003415.svg)](https://doi.org/10.5281/zenodo.14003415)

An open-source tool to facilitate environmental inventory modelling and impact assesments for LCA practitioners. It consists in a Python code based on #brightway that creates an excel spreadsheet file that together with an user-friendly interface help to input inventory data and export it to Brightway (using the bw-excel template) and Simapro (using Simapro.CSV files thanks to CSV Maker from 2.0 LCA Consultants). The scenario generation tool can also build multiple inventories within one click. Finally, the Scores tool can also calculate life-cycle impact assesment scores of product systems, useful to assess first-tier LCA results.
